# Story Splitting

## 1. Post a study listing
* Researchers need to be able to create a study listing with title, description, time commitment and reward
* Researchers need to be able to save a listing as a draft
* Researchers need to be able to publish a listing so it goes live
* Researchers need to be able to edit or close a listing after posting

## 2. Criteria
* Researchers need to define criteria for their study
* The system stores criteria added
* A user must be able to apply only if they meet the study's criteria
* The system checks a user's details against the criteria when they apply

## 3. Categorisation and grouping
* Researchers should be able to categorise the research into different areas (Social Sciences, Health, Psychology)
* Participants should be able to search studies based on characteristics
  > **Note:** Could this be a full feature/user story on its own that also needs a split? 
* The system takes information from the user to categorise them into education, income, age, race, health concerns etc. while they are applying for a study
  > **Note:** Could this be a full feature/user story on its own that also needs split? 

## 4. Manage applicants
* Researchers need to be able to view a list of applicants per study
* Researchers need to be able to accept or reject an applicant
* Researchers need to be able to export the participant list

## 5. View & Select Study Listings
* A participant should be able to see the total listing of studies
  > **Note:** Could this be a full feature/user story on its own that also needs a split?
* Participants should be able to select a number of studies to participate in.
  > **Note:** Could this be a full feature/user story on its own that also needs a split?

## 6. Tracking Sign-ups
* Researchers need to be able to view the count of the number of signed-up participants
* The system needs to indicate when a study listing is finished

## 7. Legal & Ethics
* A participants needs to be able to freely access any health/psychology concern information about a study
  > **Note:** Could this be a full feature/user story on its own that also needs split? 
* The system should reject a study uploaded without a terms and conditions, outlining concerns for the health of an individual.
* A participant cannot sign up for a study without reading a consent form.
